# 🔧 Solución para Error 405

El **error 405** en Baileys significa que WhatsApp está rechazando la conexión. Aquí están las soluciones:

## ✅ Solución 1: Limpiar sesión y reintentar

```bash
# 1. Limpia la sesión
npm run clean

# 2. Reinicia el bot
npm run dev

# 3. Escanea el nuevo QR
```

## ✅ Solución 2: Actualizar Baileys

```bash
# Actualizar a la última versión
npm install @whiskeysockets/baileys@latest

# Reiniciar
npm run dev
```

## ✅ Solución 3: Usar el bot original (más estable)

```bash
# En lugar de npm run dev, usa:
npm start
```

## ✅ Solución 4: Esperar y reintentar

A veces WhatsApp bloquea temporalmente las conexiones:

```bash
# Espera 5-10 minutos
# Luego:
npm run clean
npm run dev
```

## 🔍 Verificaciones

### 1. Verifica tu conexión a internet

```bash
ping google.com
```

### 2. Verifica que WhatsApp esté actualizado en tu teléfono

- Ve a la tienda de aplicaciones
- Actualiza WhatsApp si hay una nueva versión

### 3. Revisa que no tengas muchas sesiones activas

- WhatsApp > Dispositivos vinculados
- Cierra sesiones que no uses

## 📱 Alternativa Temporal

Mientras tanto, puedes usar el bot original que tiene configuración más básica:

```bash
# Edita src/index.js si necesitas hacer cambios
npm start
```

## 🆘 Si nada funciona

El error 405 a veces indica que WhatsApp ha marcado tu número/IP como sospechoso:

1. **Espera 24 horas** antes de intentar nuevamente
2. **Cambia de red** (usa datos móviles o otra WiFi)
3. **Usa un número diferente** para probar
4. **Considera usar WhatsApp Business API** para uso comercial

## 📞 Contacto

Si el problema persiste, considera:

- Revisar los issues de Baileys en GitHub
- Usar la versión original del bot (más estable)
- Implementar un sistema de respaldo

---

**Nota:** El error 405 es un problema conocido de Baileys y ocurre cuando WhatsApp actualiza sus protocolos de seguridad.
