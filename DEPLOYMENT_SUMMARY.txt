⚡ INICIO RÁPIDO (15-30 minutos):

  1. Lee la documentación:
     📖 cat PRODUCTION.md

  2. Prepara WhatsApp localmente:
     npm run dev
     (Escanea el QR, espera conexión exitosa)

  3. Crea instancia en AWS:
     - EC2 t2.micro (capa gratuita)
     - O Lightsail $3.50/mes

  4. Ejecuta script de instalación:
     bash deploy-ec2.sh

  5. Copia auth_info y inicia:
     docker-compose up -d
